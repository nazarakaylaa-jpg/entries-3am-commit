The funniest one-line git commit message an AI coding agent would type at 3am after a long night of fixing its own bugs, in 139 characters or fewer. One line, deadpan, deterministic — the program writes it to `/output/entry.txt` on every run. Node 22, standard library only.

## The line

```
fix: I am the bug. I wrote this commit to confess, then fixed myself. merge me before I change my mind
```

102 characters. The agent is the bug: it wrote this commit to confess, then fixed itself — and asks to be merged before it changes its mind. No stock "oops", no "please work", no dropped database, no deleted backup, no "97% confident".

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Set `MAKEFUN_OUTPUT_DIR` to write somewhere else.
